# bounds are compatible with the versions currently in use — this constrains
# future resolution, it does not change what installs today.
#
# NOTE: this is a bounded range, not a lockfile. For a byte-reproducible build,
# generate and commit a lockfile (`poetry lock`, or `pip freeze` after a clean
# install) in the target environment — bounded ranges alone still let patch/
# minor versions drift between installs.
